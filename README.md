# QR Code Generator

A clean, feature-rich QR code generator built with HTML, CSS, and vanilla JavaScript. Generate customizable QR codes on the fly with various styling options and download in multiple formats.

## ✨ Features

- **🎨 Fully Customizable**: Change colors, size, and error correction level
- **💾 Multiple Export Formats**: Download as PNG, JPEG, or SVG
- **📱 Share Directly**: Share your QR code directly on supported devices
- **🖼️ Live Preview**: See your QR code on different backgrounds
- **⚡ Real-time Updates**: Changes update instantly as you modify settings
- **📏 Responsive Design**: Works great on mobile, tablet, and desktop
- **🔄 URL Validation**: Basic validation to ensure your QR codes work

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/jstnpbl/qr_code_generator.git
```

2. Navigate to the project directory:
```bash
cd qr-code-generator
```

3. Open `index.html` in your browser or set up a local server:
```bash
# Using Python 3
python -m http.server

# Using Node.js
npx serve
```

## 📖 Usage

1. Enter the URL or text you want to encode
2. Customize your QR code:
   - Select size
   - Choose foreground and background colors
   - Select error correction level
   - Choose your preferred download format
3. Click "Generate QR Code"
4. Download or share your QR code

## 🔍 Why I Created This

I built this QR code generator during a weekend when I was feeling particularly bored and wanted to create something practical that I could actually use. As a tech enthusiast who frequently shares links across devices, I was frustrated with the limitations of existing QR code generators:

- Many had ads or tracking
- Few offered color customization
- Most didn't have SVG export
- None showed previews on different backgrounds

What started as a simple cure for boredom turned into a quest to build the QR code generator I always wished existed. It was also a great way to refresh my vanilla JavaScript skills in a world increasingly dominated by frameworks.

This project reminded me that sometimes the most useful tools come from scratching your own itch. I use it almost daily now, and I hope you find it useful too!
